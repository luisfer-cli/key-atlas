Shortcuts without the friction.

Key Atlas is a minimal Windows assistant for app-specific keyboard shortcuts, quick cheatsheets, and one-handed remap workflows.

Download installer All downloads Source code

Features

  • Context-aware shortcut library for the active app.
  • Which-key style cheatsheet overlay.
  • One-handed remap mode for compact workflows.
  • Portable executable or per-user Windows startup install.

Install

Recommended: download the Windows setup installer and follow the wizard.

Download Key Atlas installer

You can also use the portable executable for a quick test. From the tray menu, choose Install / start with Windows to keep it running after sign-in.
